## 一、Desktop GSAP 动画系统重构（#4225、#4238、#4247）

**范围最大、影响最广的变更。**

| 变更 | 说明 |
|---|---|
| `useScrollManager.ts` (新增) | 从 Transcript 中抽离滚动逻辑：stick 状态、ResizeObserver、用户消息自动滚动、rewind 跳转 |
| `useGSAPCollapse.ts` (新增) | GSAP 驱动的折叠/展开动画，替代原生 transition |
| `useEntranceAnimation.ts` (新增) | 新消息入场动画，基于 session key 防重复 |
| `gsapAnimations.ts` (新增) | 共享动画配置 |
| `Transcript.tsx` | 移除内联滚动逻辑，改用三个新 hooks；新增 `rewindSignal` prop 支持 rewind 后滚动定位 |
| `Markdown.tsx` | 流式光标定位改用 `deepestLastInlineElement()` 替代 TreeWalker |
| `ApprovalModal.tsx` | 动画改用 GSAP |
| `UndoRewindBanner.tsx` (新增) | rewind 撤销提示横幅 |
| `styles.css` | 新增动画相关样式、折叠间距统一（30px→12px） |

**合并冲突点**：Transcript.tsx 在本分支有 PR #4284 的文件链接 props（`filePathSet`/`onOpenWorkspaceFile`），合并时手工补回 prop drilling 链：
`Transcript → WarmZone → WarmTurnItems → TurnCollapse → AssistantMessage`
