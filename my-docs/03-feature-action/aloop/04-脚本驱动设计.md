## 一、完整行为模型

```
[开关 OFF] → 什么都不做
[开关 ON]  → 每 30 秒（硬编码）：
               if 会话正在 turning → 跳过本次
               else → 执行 <project-root>/.aloop/main.*
                        stdout 为空       → 跳过，无事发生
                        stdout 非空       → 作为 prompt 发送到对话
```

整个过程和「用户在输入框输入文本并发送」没有区别。计划模式、工具审批、所有现有机制照常运作。

## 二、`.aloop/` 目录规范

### 2.0 设计定位：`main.sh` 是一等公民

**aloop 的默认心智 = shell 脚本。** 理由：
- **零依赖** — macOS/Linux 自带 bash，Go 直接调 `os/exec`，不需要装 Python/Node
- **项目同源** — coding agent 日常用 bash 干活，aloop 脚本也用 bash，心智一致
- **最简单** — `#!/bin/bash` + `echo "..."` 或沉默退出，没有包管理、环境问题

`.py` / `.js` / 二进制只是作为备选——用户已经装了就能用，但默认不推荐。

### 2.1 目录文件

```
<project-root>/.aloop/
  main.sh     # ★ 一等公民，默认推荐
  main.py     # ○ 备选（用户自己装了 Python3）
  main.js     # ○ 备选（用户自己装了 Node）
  main        # ○ 备选（可执行二进制，无扩展名）
```

### 2.2 发现优先级

`main.sh` → `main.py` → `main.js` → `main`（可执行）

Controller 启动时按此顺序探测，找到第一个存在的文件锁定。

### 2.3 执行方式

| 文件 | 执行器 | 推荐度 |
|------|--------|:------:|
| `main.sh` | `bash` | ★★★ 推荐 |
| `main.py` | `python3` | ★★ 可用 |
| `main.js` | `node` | ★★ 可用 |
| `main`（可执行） | 直接执行 | ★ 兜底 |

### 2.4 stdout/stderr

| 流 | 处理 |
|----|------|
| stdout | `strings.TrimSpace(output)` → 空=跳过，非空=发送 |
| stderr | 丢弃（或 debug log） |

### 2.4 脚本示例

```bash
#!/bin/bash
# .aloop/main.sh — 监控 git 变更

if ! git diff --quiet 2>/dev/null; then
    echo "检测到未提交的代码变更，请检查。"
fi
exit 0
```

```python
#!/usr/bin/env python3
# .aloop/main.py — 定时抓取日志中的错误

import subprocess
result = subprocess.run(["tail", "-n", "5", "app.log"], capture_output=True, text=True)
if "ERROR" in result.stdout:
    print(f"发现错误日志:\n{result.stdout}")
```

```javascript
// .aloop/main.js — 检查构建目录

const fs = require("fs");
const dist = "./dist";
if (!fs.existsSync(dist) || fs.readdirSync(dist).length === 0) {
    console.log("构建目录为空，可能需要重新构建。");
}
```

## 三、Controller 层设计

### 3.1 新增字段

```go
// Controller struct
loopActive   bool                
loopCancel   context.CancelFunc  
loopRoot     string              // 项目根目录，定位 .aloop/
loopScript   string              // 探测到的脚本路径
loopExecutor string              // "bash" / "python3" / "node" / ""
```

### 3.2 新增方法

```go
// 启动 aloop
func (c *Controller) StartLoop(projectRoot string) error {
    // 1. 若已 active → return error
    if c.loopActive { return errors.New("loop already active") }
    
    // 2. 探测脚本
    candidates := []struct{ file, exe string }{
        {"main.sh", "bash"},
        {"main.py", "python3"},
        {"main.js", "node"},
        {"main", ""},  // 可执行，直接执行
    }
    var scriptPath, executor string
    for _, cand := range candidates {
        path := filepath.Join(projectRoot, ".aloop", cand.file)
        if _, err := os.Stat(path); err == nil {
            scriptPath = path
            executor = cand.exe
            break
        }
    }
    if scriptPath == "" { return errors.New(".aloop/main.* not found") }
    
    // 3. 启动 goroutine
    ctx, cancel := context.WithCancel(context.Background())
    c.loopActive = true
    c.loopCancel = cancel
    c.loopRoot = projectRoot
    c.loopScript = scriptPath
    c.loopExecutor = executor
    
    go c.loopRunner(ctx)
    return nil
}

// 停止 aloop
func (c *Controller) StopLoop() {
    if c.loopCancel != nil { c.loopCancel() }
    c.loopActive = false
}

// 查询状态
func (c *Controller) LoopActive() bool { return c.loopActive }
```

### 3.3 loopRunner 核心循环

```go
func (c *Controller) loopRunner(ctx context.Context) {
    ticker := time.NewTicker(30 * time.Second)
    defer ticker.Stop()
    
    for {
        select {
        case <-ctx.Done():
            return
        case <-ticker.C:
            // 检查是否正在 turning
            c.mu.Lock()
            turning := c.running
            c.mu.Unlock()
            if turning { continue }
            
            // 执行脚本
            output := c.execLoopScript()
            trimmed := strings.TrimSpace(output)
            if trimmed == "" { continue }
            
            // 发送到对话（Send 内部有互斥，自动排队）
            c.Send(trimmed)
        }
    }
}
```

### 3.4 脚本执行辅助函数

```go
func (c *Controller) execLoopScript() string {
    var cmd *exec.Cmd
    switch c.loopExecutor {
    case "bash":
        cmd = exec.Command("bash", c.loopScript)
    case "python3":
        cmd = exec.Command("python3", c.loopScript)
    case "node":
        cmd = exec.Command("node", c.loopScript)
    default:
        cmd = exec.Command(c.loopScript)  // 可执行二进制
    }
    
    var stdout bytes.Buffer
    cmd.Stdout = &stdout
    cmd.Dir = c.loopRoot  // 在项目根目录下执行
    
    if err := cmd.Run(); err != nil {
        return ""  // 脚本执行失败，静默跳过
    }
    return stdout.String()
}
```

### 3.5 关键行为

| 场景 | 行为 |
|------|------|
| turning 中 tick 触发 | ticker 层面跳过本次，等待下个 tick |
| turning 刚结束、tick 立即触发 | `c.running` 为 false → 执行脚本 → 非空则 `c.Send()` |
| Send 时恰好开始新 turn | `Send` 内部互斥锁排队，等本轮 turn 结束后再处理 aloop 的 prompt |
| 脚本执行失败 | 静默跳过，不发消息 |
| 脚本 stdout 为空 | 静默跳过，不发消息 |
| 脚本超时 | 暂无超时保护（MVP 版本，后续可加 `cmd.Context` 超时） |
| plan mode 开启 | 正常——aloop 的 prompt 进入后，走 plan 审批流程。和手动输入一致 |

## 四、Desktop 后端设计

### 4.1 `desktop/app.go` — Wails 绑定

```go
func (a *App) StartLoop() error {
    tab := a.currentTab()
    if tab == nil { return errors.New("no active tab") }
    return tab.Ctrl.StartLoop(tab.WorkspaceRoot)
}

func (a *App) StopLoop() {
    tab := a.currentTab()
    if tab == nil { return }
    tab.Ctrl.StopLoop()
}

func (a *App) LoopActive() bool {
    tab := a.currentTab()
    if tab == nil { return false }
    return tab.Ctrl.LoopActive()
}
```

### 4.2 前端 UI（MVP 跳过）

MVP 阶段没有按钮、没有开关。用户通过 Wails devtool 控制台或后续加的简单 panel 来调用。
