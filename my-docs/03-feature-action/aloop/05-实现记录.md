## 设计

```
aloop = 开关 ON → 每 30 秒：
                 if turning → 跳过
                 else → 执行 .aloop/main.sh (bash)
                        stdout 非空 → 作为 prompt 发送到对话
                        stdout 为空 → 静默跳过
```

- **配置**: 无。30 秒硬编码
- **持久化**: 无。重启即关
- **脚本**: 仅 `main.sh`（bash），优先查找，次选 .py / .js / 二进制
- **UI**: Composer 右下角「普通 | 定时检测」两段式开关，紧接 tool approval modebar

## 用法

1. 在项目根目录创建 `.aloop/main.sh`：
   ```bash
   #!/bin/bash
   if ! git diff --quiet 2>/dev/null; then
       echo "检测到未提交的代码变更"
   fi
   ```
2. 在 Desktop 中点击 Composer 右下角「定时检测」按钮
3. 每 30 秒执行一次，stdout 非空则发送到对话
